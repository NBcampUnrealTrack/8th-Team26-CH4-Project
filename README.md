## 게임 소개

**Left Behind**는 무너진 도시를 배경으로, 플레이어들이 힘을 합쳐 거대한 **기계 신수**를 사냥하는 협동 액션 RPG입니다.

보스를 무작정 때리는 게임이 아닙니다. 플레이어는 보스의 움직임을 읽고, 팀원과 위치를 맞추고, 결정적인 순간에 모든 화력을 집중해야 합니다. 핵심은 단 하나입니다.

> **5분 안에 보스를 쓰러뜨리고, 다음 도전에서는 더 빠르게 클리어하는 것.**

## 플레이 흐름

```txt
보스 패턴 확인
      ↓
회피 / 가드 / 위치 조정
      ↓
공격과 스킬 사용
      ↓
협동 기믹 성공
      ↓
10초 그로기 집중 공격
      ↓
클리어 시간 단축
```

첫 목표는 **5분 이내 클리어**입니다. 익숙해질수록 3분, 1분 기록에 도전하며 같은 보스를 더 빠르게 공략하는 재미를 추구합니다.

---

## 세계관

도시는 오래전에 무너졌고, 남겨진 기계 문명은 통제를 잃었습니다.

그 잔해 속에서 깨어난 거대한 기계 신수들은 폐허를 배회합니다. 플레이어는 이 세계에 남겨진 사냥대의 일원이 되어, 무너진 문명 위를 짓밟는 기계 신수들을 추적하고 사냥합니다.

## 첫 번째 보스 콘셉트

### 폐철왕 아르고스

전쟁 전 자동방위병기가 폭주해 짐승 형태로 변형된 거대 기계 생명체입니다. 낡은 금속 외피와 과열된 에너지 코어를 가진 아르고스는, 폐허 도시의 중앙 광장을 짓밟으며 플레이어를 압박합니다.

| 공격 | 대응 방식 |
| --- | --- |
| 전방 휘두르기 | 보스 측면으로 이동하거나 회피 |
| 돌진 | 좌우로 피한 뒤 노출된 빈틈 공격 |
| 충격파 | 타이밍에 맞춰 점프 또는 회피 |
| 광폭화 | 생존을 우선하며 다음 그로기 타이밍 준비 |
