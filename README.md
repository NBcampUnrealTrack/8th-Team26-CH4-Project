## 게임 소개

**Left Behind**는 아포칼립스 이후의 폐허 도시를 배경으로 펼쳐지는 **3인칭 협동 보스 레이드 액션 RPG**입니다.

플레이어는 혼자서 모든 것을 해결하는 영웅이 아닌, 서로 다른 능력을 지닌 사냥대의 일원이 됩니다.

팀원과 역할을 나누고, 보스의 공격을 회피하며, 협동 기믹을 수행해 결정적인 공격 기회를 만들어야 합니다.

보스의 움직임을 읽는 판단력, 위험 속에서도 자신의 역할을 수행하는 책임감, 그리고 동료들과 완벽한 타이밍을 만들어내는 협동이 승리를 결정합니다.

| 구분 | 내용 |
| --- | --- |
| **장르** | 협동 보스 레이드 / 3인칭 액션 RPG |
| **플랫폼** | PC |
| **플레이 방식** | 실시간 멀티플레이 |
| **배경** | 아포칼립스 이후의 폐허 도시 |
| **핵심 경험** | 보스 공략, 역할 분담, 협동 기믹, 기록 단축 |

## 에디터 로컬 실행

EOS Artifact가 아직 설정되지 않은 에디터 빌드는 자동으로 로컬 LAN 테스트 모드로 전환됩니다. 이 모드에서는 방 생성·검색·참가를 같은 PC 또는 같은 LAN에서 테스트할 수 있지만, Epic 계정 로그인·인터넷 방 검색·친구 초대는 사용할 수 없습니다.

에디터에서도 실제 EOS를 사용하려면 `Scripts/SetupEOSDev.ps1`을 실행해 `Config/GeneratedEngine.ini`를 만든 뒤 에디터를 완전히 재시작하세요. 해당 파일에는 Client Secret이 포함되므로 커밋하거나 공유하지 마세요.

---

## 다른 PC용 EOS 패키징

대상 PC에는 EOS 프로젝트 값을 따로 설정하지 않습니다. 빌드 PC에서만 `Scripts/SetupEOSDev.ps1`로 EOS 자격 정보를 한 번 등록한 뒤 다음 명령으로 Win64 패키지를 생성합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\Scripts\PackagePortableWin64.ps1
```

완료 후 스크립트가 마지막에 출력하는 폴더 전체를 전달하세요. 스크립트는 EOS Artifact 설정이 유효한지 먼저 검사하고, 게임 실행 파일·EOS SDK DLL·EOS Bootstrapper·공식 EOS Redistributable Installer·pak/IoStore·VC++ 필수 구성 요소가 모두 포함되었는지 검증합니다. 대상 PC에서는 `StartLeftBehind.cmd`만 실행하면 됩니다. 최초 실행 시 VC++ 필수 구성 요소와 EOS Redistributable 설치를 위한 Windows 관리자 권한 확인만 승인하면 되며, Product/Sandbox/Client 값 입력이나 `SetupEOSDev.ps1` 실행은 필요하지 않습니다. 설치 관리자가 재부팅을 요구하는 경우 Windows를 한 번 재시작한 뒤 같은 파일을 다시 실행하세요.

`Config/GeneratedEngine.ini`에는 Client Secret이 포함되므로 Git에 커밋하거나 별도로 전달하지 마세요. 패키징된 클라이언트에는 EOS 접속에 필요한 런타임 자격 정보가 포함되므로 Developer Portal의 Client Policy는 게임에 필요한 최소 권한만 허용해야 합니다.

## 세계에 남겨진 사람들

인류 문명이 무너진 뒤, 도시는 더 이상 사람들의 것이 아니게 되었습니다.

붕괴된 도로와 버려진 건물 사이에는 전쟁의 흔적이 남아 있고, 한때 인류를 지키기 위해 만들어졌던 거대한 기계 병기들은 폭주한 신수로 변해 폐허를 지배합니다.

하지만 모든 사람이 이 세계를 포기한 것은 아닙니다.

살아남은 사냥대는 각자의 무기와 능력을 들고 다시 도시로 향합니다.

이제 여러분은 동료들과 함께 기계 신수의 패턴을 파악하고, 약점을 무너뜨려 인류가 잃어버린 땅을 되찾아야 합니다.

> **우리는 살아남기 위해 싸우는 것이 아니다.**  
> **다시 살아갈 수 있는 세계를 만들기 위해 싸운다.**

## 함께 싸우고, 기회를 만들어라

### 거대한 기계 신수와의 전투

압도적인 크기의 기계 신수는 단순한 공격만으로 쓰러뜨릴 수 없습니다.

보스는 넓은 범위를 휩쓰는 공격과 돌진, 충격파, 약점 코어 노출 등 다양한 패턴으로 플레이어를 위협합니다.

공격 전 나타나는 움직임과 신호를 관찰하고, 적절한 위치로 이동해 다음 행동에 대비해야 합니다.

싸움이 계속될수록 보스는 더욱 거칠어지고 전장은 위험해집니다.

---

### 팀워크로 완성하는 협동 기믹

전투 중에는 혼자 해결하기 어려운 특별한 기믹이 등장합니다.

흩어진 장치를 작동시키거나, 제한 시간 안에 여러 약점 코어를 파괴하는 등 팀원 모두가 자신의 임무를 수행해야 합니다.

누가 먼저 움직일지, 누가 보스의 시선을 끌지, 언제 공격을 집중할지 빠르게 판단하세요.

완벽한 협동은 전투의 흐름을 뒤집을 수 있습니다.

---

### 단 10초, 모든 것을 쏟아부어라

협동 기믹에 성공하면 보스가 **10초 동안 그로기 상태**에 빠집니다.

이 짧은 순간이 전투에서 가장 강력한 공격 기회입니다.

남은 스킬과 자원을 집중하고, 팀원들과 공격 타이밍을 맞춰 최대한 많은 피해를 입히세요.

단 한 번의 완벽한 10초가 승리와 패배를 가릅니다.
